Get Datasetto on your devices

The web app is the full experience and needs nothing installed. The native shells add a tray icon, global push to talk, system notifications and a proper screen picker with system audio.

Builds are published on GitHub Releases.

Web app

Chrome, Edge, Firefox and Safari on desktop, plus a phone layout. Add it to your home screen for an app-like window.

Desktop

Windows, macOS and Linux. Share any window or screen with system audio and mute from the tray.

Android

Voice keeps running in the background and the camera flips between front and back. Install the APK directly; Android asks once to allow installs from your browser.

Build it yourself

Everything is open source under the GNU AGPLv3. The iOS app is built from the same code with Xcode.

Which server does the app connect to? The web app talks to the server that serves it. The desktop and Android apps ask for a server address on first start, or read it from runtime-config.json next to the desktop executable. Your friends simply enter the address of the server you run.
