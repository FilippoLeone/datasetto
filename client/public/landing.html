Everything a group needs

Familiar where it matters, lighter everywhere else

The parts of a chat app your friends actually use, without the parts that sell them something.

Voice that feels close

Peer-to-peer WebRTC with echo cancellation, noise suppression, a noise gate and push to talk. Per-person volume, camera tiles and keyboard shortcuts included.

Go live, with or without OBS

Share a game with system audio straight from the app, or point OBS at your server and let everyone watch in a low-latency theater view with live chat.

Screen sharing rooms

One presenter, many viewers. Fullscreen playback, 60 fps when the connection allows it, and nothing leaves your server.

Minigames in voice

Start Slither, Pacman or a side-view brawl right inside a voice channel while you talk. Scores are kept on a leaderboard, grudges are kept by you.

Roles and invites

Invite-only registration, admin, moderator and streamer roles, per-channel permissions, bans and voice timeouts. The first account becomes the owner.

Yours to run

One Docker Compose file, one SQLite database, automatic HTTPS and nightly backups. Read the code, change it, keep it. GNU AGPLv3.

Self-hosting

Online in an evening, not a weekend

Datasetto is built for a single small machine. No Kubernetes, no managed database, no load balancer. A domain, a VM and Docker are all it takes.

  1. Copy the example configSet your domain, an invite code and your admin email.
  2. Start the stackCaddy gets a certificate, the API starts, the RTMP server waits for OBS.
  3. Invite your friendsShare the link and the invite code. The first account to register becomes the owner.
# clone, configure, run
git clone https://github.com/FilippoLeone/datasetto
cp ops/.env.example ops/.env   # domain, invite code, admin
docker compose -f ops/docker-compose.yml up -d

# or let the script create the VM on Google Cloud
ops/gcp/create-vm.sh
≈ €13/month for the whole thing on one e2-micro VM, streaming included. Less in the US free-tier regions.

FAQ

Good questions

Is Datasetto free?

Yes. It is open source under the GNU AGPLv3. You only pay for the server you run it on, which can be a single small virtual machine.

Do I need OBS to stream?

No. Share your screen with system audio straight from the app, like a go-live button. OBS is supported too for scene-based streams: it publishes to your server and viewers watch as low-latency HLS with chat next to the video.

How many people can use it?

It is built for a group of friends. Voice and screen sharing are peer to peer, so a room of five to ten people works well on a small server and ordinary home connections.

Does it work on phones?

Yes. The web app adapts to phones, and there is an Android app plus Electron desktop apps for Windows, macOS and Linux.

Where is my data stored?

On your own server, in one SQLite file. Media never touches the server except RTMP ingest and the optional TURN relay. There is no tracking and no third party.

Bring the group over

Spin up your own server tonight, or just open the app if a friend already runs one.
