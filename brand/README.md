# Datasetto brand

The mark is **Orbit**: a planet with a tilted ring that passes in front of it, a small world of your own. Every icon, splash screen and logo file in the repository is drawn from one place, [orbit.mjs](orbit.mjs), by [generate.mjs](generate.mjs).

| Colour | Hex | Used for |
| --- | --- | --- |
| Amber | `#FFAE3B` | planet, top left of the gradient |
| Persimmon | `#FF6A3D` | planet, bottom right of the gradient |
| Teal | `#12A89D` | ring |
| Night | `#17222B` | tiles, splash screens, the Android icon background |

On tiles (macOS, iOS, apple-touch, maskable web icons) Night is a gentle gradient from `#22313D` to `#121B22`. The mark works on light and dark backgrounds as it is; for a one-colour version use `logo-mono.svg` (black, recolour freely). The app interface keeps its own colours; these are for the logo.

## Files here

- `orbit.mjs`: the source. The master geometry (`MASTER`, on a 256 unit canvas), hand-tuned parameters for 20, 24 and 32 px (`TUNED`) and the hand-drawn 16 px pixel map (`PIXELS_16`). The ring and the cut-outs are plain circle and ellipse arcs, so the same paths work as SVG and as Android vector drawables.
- `generate.mjs`: writes every output listed below.
- `logo.svg`, `logo-mono.svg`, `logo-tile.svg` (the mark on a Night square, 1024), `logo-1024.png`: generated, for anyone who needs the logo (social cards, the landing page, slides).
- `preview.png`: a contact sheet of every output when the mark was introduced (not regenerated by the script).

## Regenerate

```bash
cd brand
npm ci
node generate.mjs                    # everything
node generate.mjs --only desktop,web # some of: brand, desktop, web, android, ios, client
```

The outputs are committed. Builds (desktop packaging, the release workflow, the Android and iOS projects) use them as they are and never run the generator.

## Outputs

- `desktop/resources/`: `icon.ico` (16, 20, 24, 32, 40, 48, 64, 128, 256; Windows app, installer and shortcuts), `icon.png` (1024; Linux packages and the window icon), `icon.icns` (macOS, the mark on a Night tile), `tray-idle`, `tray-connected`, `tray-speaking`, `tray-muted` (`.ico` 16 to 48 and a 32 px `.png`), `icon-speaking` (`.ico` and `.png`, a green taskbar overlay badge).
- `client/public/`: `favicon.ico` (16, 32, 48; the tab icon), `favicon.svg`, `icon-192.png` and `icon-512.png` (the bare mark), `icon-maskable-192.png` and `icon-maskable-512.png` (Night background, the mark inside the safe circle), `apple-touch-icon.png`.
- `client/src/components/logoMark.ts`: the paths and colours for the in-app `<Logo>` component.
- `mobile/android/app/src/main/res/`: `ic_launcher`, `ic_launcher_round` and `ic_launcher_foreground` in every mipmap density, the adaptive icon XML with a monochrome layer for Android 13 themed icons (`drawable/ic_launcher_monochrome.xml`), the Night background colour, the notification icon `drawable/ic_stat_datasetto.xml` and `splash.png` in every drawable density and orientation.
- `mobile/ios/App/App/Assets.xcassets/`: the 1024 App Store icon and the three splash images.

`client/public/og-image.png` (the social card) is drawn by `client/scripts/brand-assets.py`, which takes the mark from `brand/logo-1024.png`: rerun it after changing the mark. `client/public/landing.html` uses `/favicon.svg`.

## Tray states

| State | Look |
| --- | --- |
| idle (not in a voice channel) | the mark in grey |
| connected | the mark in colour |
| speaking | the mark with a green dot |
| muted | the mark with a red dot crossed out |

The grey, green and red are the client's own idle, speaking and danger colours, chosen to read on both light and dark Windows taskbars.

## Rules for changes

- No text inside the icon. The name sits next to the mark, never in it.
- Check 16, 20, 24 and 32 px after any change to the geometry: retune `TUNED` and redraw `PIXELS_16` rather than letting them become plain scale-downs.
- Windows caches icons. After a release, the installed app and pinned shortcuts may keep the old icon until the cache refreshes (sign out and in, or run `ie4uinit.exe -show`).
